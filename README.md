# EasyMart Enhanced Flutter app

A mobile-first grocery shopping experience built with a single Flutter codebase for Android and iOS.

## Features
- Grocery category system: Fruits, Vegetables, Dairy, Meat, Pantry, Frozen, Bakery
- Search and category filtering
- Weekly and monthly purchase analytics
- Order history and summary cards
- Order detail sheet with product visuals
- Real product images from Unsplash

## Getting started
1. Install Flutter SDK.
2. Run:
   ```bash
   flutter pub get
   flutter run
   ```

## Project structure
- `lib/main.dart` — complete app implementation in one file
- `pubspec.yaml` — app configuration

## Notes
This app is designed as a single-codebase mobile experience that can run on both Android and iOS with the same shared UI logic.
